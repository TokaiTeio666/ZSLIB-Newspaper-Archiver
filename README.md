# ZSLIB-Newspaper-Archiver（近代报纸数据库版）

## 项目简介
本项目是一个自动化工具，旨在从**广东省立中山图书馆 - 中国历史文献总库·近代报纸数据库**批量采集历史报纸资源。它能够自动导航至近代报纸数据库，执行关键词搜索，遍历搜索结果，精确裁剪高清原图，并将每一篇报纸条目按照标准化的格式保存为独立的 Word (.docx) 文档，便于后续的史料研究与整理。

## 核心功能
- **自动导航**：自动从广东省立中山图书馆报纸资源页进入"中国历史文献总库·近代报纸数据库"。
- **自动化采集**：支持关键词搜索、多页结果自动翻页，直至尾页。
- **高清原图裁剪**：通过 `PIL (Pillow)` 库计算原图与网页显示的比例，实现坐标精准对齐的高清裁剪。
- **文字信息提取**：自动提取详情页中的篇名、作者等文字信息，并写入文档。
- **标准化文档生成**：自动解析报刊名、日期及版次信息，生成符合排版要求的 Word 文档。
- **智能文件命名**：自动清洗非法字符，以"日期_报刊名"命名，确保文件系统兼容性。

## 文档格式
生成的 Word 文档遵循以下格式：
```
xx年
xx月
xx日
[文字内容：篇名、作者等]
[高清裁剪图片]
                          ——《xx日报》xx年xx月xx日，第xx版
```

## 技术栈
- **Python 3.x**
- **Selenium**: 网页自动化与动态内容交互（Edge 浏览器）。
- **python-docx**: 生成并操作 Word 文档。
- **Pillow (PIL)**: 图像处理与高清裁剪坐标计算。
- **Requests**: 负责高清大图的二进制数据下载。

## 快速开始

### 环境配置
1. 安装依赖库：
   ```bash
   pip install selenium python-docx pillow requests
   ```
2. 确保已安装 Microsoft Edge 浏览器（Selenium 会自动管理驱动）。

### 使用方式

#### 方式一：GUI 界面（推荐）
```bash
python gui.py
```
在界面中输入搜索关键字，选择输出目录，点击"开始采集"。

#### 方式二：命令行
```bash
python main.py
```
按提示输入搜索关键字即可。

### 注意事项
1. **访问权限**：本工具需要在广东省立中山图书馆馆内网络环境下运行，或通过馆外访问系统登录后使用。
2. **登录等待**：程序启动后会自动打开浏览器并导航至数据库，如遇登录页面请在 20 秒内完成登录。
3. **首次运行**：首次运行时 Selenium 可能需要下载 Edge 驱动，请保持网络畅通。

## 数据库说明
本工具适配的数据库为**中国历史文献总库·近代报纸数据库**（国家图书馆出版社开发），广东省立中山图书馆镜像库发布了广东地区约二十份民国时期报纸（包括广州日报、岭南日报等）。

数据库访问入口：
- 广东省立中山图书馆报纸资源页：`https://www.zslib.com.cn/Page/Page.html?t=bz`
- 数据库官方平台：`https://bz.nlcpress.com/`
